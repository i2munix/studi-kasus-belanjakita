# Studi Kasus Ulasan PT BelanjaKita Digital

Aplikasi Streamlit untuk jawaban studi kasus FR.IA.04A, skema Insinyur Pembelajaran Mesin (Machine Learning Engineer).
Data di folder `data/` adalah data rekaan (dummy); nama dan nomor telepon di dalamnya fiktif.

| Aplikasi | Kelompok Pekerjaan |
|---|---|
| `kp1_fika.py` | KP1 – Penentuan dan Pembuatan Proyek Data Science |
| `kp2_imamah.py` | KP2 – Pembangunan dan Pengevaluasian Model |
| `kp3_firdaus.py` | KP3 – Pelaksanaan Deployment dan Pemeliharaan Model |

Menjalankan secara lokal:

```
pip install -r requirements.txt
streamlit run kp2_imamah.py
```
